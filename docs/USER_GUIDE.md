# User Guide

1. Start the app with `streamlit run app.py`.
2. Create an account with an email and a password of at least 10 characters, then sign in.
3. Edit profile details and the skills you personally confirm in **My Profile**.
4. Upload a text or PDF resume in **Resume Intelligence**, review detected terms and extracted text, and explicitly save it. Files are processed locally. PDF requires PyMuPDF; scanned PDFs are not OCR processed.
5. Add self-reported proficiency levels in **Skill Assessment**. This is kept separate from resume mentions.
6. Explore the ESCO occupation profiles with Career Explorer, matching, and skill-gap pages. This is a standardized occupation and skill classification, not a live vacancy feed. Similarity is not a hiring probability.

Change a password from the Privacy page; you will be signed out afterward. If you lose access, an administrator can issue a one-time temporary password and share it with you through a secure channel; there is no email recovery flow. The Privacy page offers account-data export and account deletion.
